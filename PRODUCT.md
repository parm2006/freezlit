# freezlit

## Platform
Windows desktop window with local web UI, confirmed by user.

## Stack
Python local service and pywebview, vanilla HTML/CSS/JavaScript. Implementation chosen to minimize runtime dependencies.

## Users and purpose
Individuals making and studying local text/image decks. Combine scheduled recall with varied practice and tests. Share decks through exported files; no account required.

## Constraints
Local storage, installable Windows build, basic pleasant UI. Support either question direction. Exact parity with every Anki/Quizlet feature is not established. Feature evidence and limits live in FEATURES.md.

## Visual commitment
Quiet cream and green notebook interface, clear mode navigation and readable study cards. User requested basic and pleasant.
